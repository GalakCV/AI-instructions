# AI Instructions

Instructions and starter prompts for authorized bug bounty research.

| Chat | Instructions | Starter prompt |
| --- | --- | --- |
| Questions | [questions.txt](instructions/questions.txt) | [start-questions.txt](prompts/start-questions.txt) |
| Bug Bounty Skills | [bug-bounty-skills.txt](instructions/bug-bounty-skills.txt) | [start-bug-bounty-skills.txt](prompts/start-bug-bounty-skills.txt) |
| Caido Analysis | [caido-analysis.txt](instructions/caido-analysis.txt) | [start-caido-analysis.txt](prompts/start-caido-analysis.txt) |

Paste the matching instructions into each chat's setup or first message. Then use its starter prompt, replacing bracketed fields with your actual context and program policy.

Caido Analysis requires a connected Caido MCP and defaults to inspecting existing traffic only. Prompts are written in English; Questions and Analysis request answers in Brazilian Portuguese.
